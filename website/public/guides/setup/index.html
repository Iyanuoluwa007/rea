Set up REA,
one step at a time.

Only used AI in a web browser? Start here. Each step says what to click, what to type and what you should see.

About 15 minutes · Mac, Windows or Linux · No coding needed

How the pieces fit

The AI chat in your web browser can't open programs or files on your computer. A desktop AI app can, once a tool such as REA is connected to it. REA is the part that looks inside a program and reports what it finds.

Words you'll see on this page
Terminal
A window where you type instructions instead of clicking. Every computer has one.
Command
One line of text you paste into the terminal and run by pressing Enter.
Path
The address of a file or folder, such as /Users/sam/Downloads/notes-example. Step 8 shows how to copy one.
MCP
The standard way AI apps connect to tools like REA. Setup configures it for you; you never edit it by hand.

Step 1

Get an AI app for your computer

Pick the one that matches the AI you already use:

  • You use Claude in the browser. Install Claude Desktop and sign in with the same account.
  • You use ChatGPT. Install Codex, OpenAI's coding agent, and sign in with your ChatGPT account.
  • You already use a coding agent such as Claude Code, Cursor or Gemini CLI. Keep it and go to step 2.

Open the app once to finish signing in, then leave it. This guide shows Claude Desktop; the other apps follow the same steps.

Step 2

Install Node.js

REA runs on Node.js, a free program that many developer tools use. REA doesn't install it for you, so do this once:

  1. Open the Node.js download page.
  2. Choose the LTS version (“long-term support”) and the installer for your computer: a .pkg file on a Mac or an .msi file on Windows.
  3. Open the downloaded file and click Continue or Next until it finishes. Keep the default options.

On Linux, use the instructions for your distribution on the same page. REA works with Node.js 22 (22.19 or newer), 24 (24.11 or newer) and 26 or newer.

Step 3

Open the terminal

  • Mac: press ⌘ Command + Space, type Terminal and press Return.
  • Windows: press the Windows key, type cmd and press Enter to open Command Prompt. Use Command Prompt rather than PowerShell for these steps.
  • Linux: press Ctrl + Alt + T, or open Terminal from your apps.

Check that Node.js is installed. Type this line, then press Enter:

node -v

If the terminal says command not found or is not recognized, close the terminal, open a new one and try again. A terminal opened before the installation can't see Node.js yet.

Step 4

Run REA setup

Click Copy, paste the command into the terminal and press Enter:

npx rea-agents@latest setup

To paste: ⌘ Command + V on a Mac, Ctrl + V in Windows Command Prompt, or Ctrl + Shift + V in most Linux terminals.

The first time, npm asks before downloading REA. Type y and press Enter.

Step 5

Choose your AI app

Setup shows a list of AI apps. Use the keyboard:

  1. Press ↓ to move to your app, for example Claude Desktop.
  2. Press Space to tick it. The empty box ◻ turns into a filled box ◼.
  3. Press Enter to continue.

On a Mac or Linux, setup may also ask “Install Hopper for deep binary analysis?” Press Enter to keep No. You only need Hopper for compiled programs, and you can add it later from the native analysis setup.

Step 6

Approve the changes

Before it changes anything, setup lists exactly what it will do.

  • CREATE adds REA to your AI app's settings file. Your other settings stay as they are; if the file already exists, setup keeps a backup.
  • INSTALL adds a short instruction set that teaches coding agents how to use REA.

Yes, apply is already selected. Press Enter. To stop instead, press Ctrl + C; nothing is changed.

Step 7

Restart your AI app

When setup finishes, it tells you what to restart:

Quit the app completely, then open it again. Closing its window isn't enough:

  • Mac: click the app, then press ⌘ Command + Q.
  • Windows: choose Quit or Exit from the app's menu, or right-click its icon next to the clock and choose Quit.
  • A terminal agent such as Claude Code or Codex: exit it and start it again.

You can close the terminal now.

Step 8

Ask your first question

Try REA on a small example app with an Export notes button. You don't need to run it; REA reads its code.

  1. Download the example ZIP and unzip it: double-click it on a Mac, or right-click it on Windows and choose Extract All.
  2. Copy the prompt below and paste it into your AI app. Don't send it yet.
  3. Copy the path of the notes-example folder:
    • Mac: right-click the folder, hold ⌥ Option and choose Copy “notes-example” as Pathname.
    • Windows: right-click the folder and choose Copy as path. On Windows 10, hold Shift while you right-click.
  4. Paste the path at the end of your message and send it. If your app asks whether it may use a REA tool, allow it.

If something goes wrong

“command not found: npx” or “'npx' is not recognized”

The terminal can't find Node.js. Close every terminal window, open a new one and run node -v. If it still fails, install Node.js again from step 2.

“running scripts is disabled on this system”

You're in Windows PowerShell, which blocks npx on many computers. Open Command Prompt instead (step 3) and paste the command there.

Setup says my Node.js version isn't supported

Install the current LTS version from step 2, open a new terminal and run setup again.

My AI app doesn't use REA

Quit the app completely and open it again (step 7). If it still doesn't, check the connection from the terminal. For Claude Desktop:

npx rea-agents@latest doctor --client claude_desktop

The first line should say healthy: true. Lines about Hopper, Ghidra and IDA only matter for compiled programs. For another app, replace claude_desktop with codex, claude_code, cursor or gemini_cli.

I chose the wrong app, or want to add another

Run the setup command from step 4 again. Apps you already connected are ticked; tick the one you want and press Enter.

Still stuck? Read the FAQ, ask in the REA community or report a problem. Include what you typed and what the terminal printed.
